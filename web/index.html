THE 4 FORENSIC SUPERPOWERS

Laya doesn't just play games. Every calculation is recorded, auditable, and scientifically evaluated.

USP 01 #/autopsy

Decision Autopsy

Compare what Laya predicted with what actually happened, turning failed moves into testable forensic hypotheses.

🔍 Investigates confident misses & lucky hits
USP 02 #/lab

Question Lab

A/B test perception-first formulations against direct-action controls on identical seeds to measure real gameplay metrics.

🧪 Rigorous offline seed benchmarks
USP 03 #/replay

Reproducible Run Replay

Inspect unmodified recorded events with cryptographic SHA-256 verification and absolute move-to-Laya traceability.

📼 Step-by-step audit with zero rewriting
USP 04 #/calibration

Confidence Reality Check

Plot model confidence against empirical success rate to detect overconfidence and compute Expected Calibration Error (ECE).

COMPLIANCE GUARANTEE

THE NON-NEGOTIABLE RULES

Our architecture is built specifically for strict hackathon auditing. We never fabricate data or employ hidden fallback policies.

  • ✔ Laya is the only decision maker: No chatbots, heuristic policies, or random actions choose moves.
  • ✔ 100% Traceability: Every submitted action traces back to an immutable, logged Laya inference event.
  • ✔ Zero Hallucinated Metrics: Missing values remain null; demo values are visibly labeled DEMO.
  • ✔ Game Day Adaptability: Plug-and-play adapter interface ensures no engine rewrites on game day.
